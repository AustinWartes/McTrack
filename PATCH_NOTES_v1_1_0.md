# 1.1.0 experimental personal build
App: dark material, reduced tint, floating Done control, toggle cube settings, saturated origin axes and wider halo, reduced reveal, thicker target texture (approximate), export version and schema metadata. Existing corners, calibration and written timestamps retained.
Blender: install McTrack_addon.zip. Run BlenderAddon/setup_solver.bat (Python 3.11 required), set Solver Python to the printed path. Select imported camera or rigid controller, choose scope and run Advanced refinement. Esc cancels. Original/Refined switches take actions. Basic stabilization is collapsed. Solver uses PyAV PTS, AprilTag redetection, robust per-frame reprojection, legacy calibration reconstruction, optical flow and sparse camera bundle adjustment with pose priors. Camera changes compensate rigid poses. Reports are fit residuals, not independent accuracy measurements. Camera solver uses fixed first-sample intrinsics, heuristic static-feature rejection, no explicit person mask; rigid calibration is reconstructed for legacy takes but not globally optimized; no temporal bundle adjustment or explicit missing-frame recovery. Rigid-only uses original source camera, not arbitrary edited camera. Maximum currently same iteration budget as High. No iOS or Blender runtime validation; external dependencies not installed here. No real recording solve validated. Keep v1.0.1 backup.
