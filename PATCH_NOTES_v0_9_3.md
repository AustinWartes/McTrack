# McTrack v0.9.3 — Optical Glow Polish

- Tuned coral palette to bridge UI salmon and ground grid red.
- Reduced control halo radius and introduced a fine near-white inner stroke.
- Lightened glass panels, added separate glass capsules for resolution and FPS, and a subtle top vignette.
- Refined framed wordmark corners with narrow white-hot highlights.
- Replaced concentric grid dot circles with a continuous radial color/alpha gradient; reduced dot footprint.
- Added additive blending to the ground grid material and faint additive sleeves to SceneKit axis/tag bracket geometry.
- Preserved recording, raw tag measurements, tracking mode and Blender importer from v0.9.2.

This project has not been compiled on Xcode; validate in GitHub Actions and on device.
