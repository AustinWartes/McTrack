# iOS 1.2.0 release candidate
Home screen, recording library, native video rotation and replay overlays. Rotation is locked at capture start and exported as videoRotationDegrees (clockwise native sensor to encoded image), with dimensions and FPS taken from the writer. Portrait remains 90 degrees; landscapeRight 0, landscapeLeft 180. Includes Blender 1.3.1 unchanged. Replay uses original video with timestamp-based projected axes, tag outlines and cube wireframe, interpolating gaps up to 150 ms without changing exported data. No extra video file. Existing recording folders remain readable when compatible metadata and timestamps exist. Device orientation, AR preview, overlay alignment, landscape UI and build must be verified on iPhone; Linux Swift parser is not an iOS SDK type check.
