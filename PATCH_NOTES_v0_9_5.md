# v0.9.5 — Saturated Coral Grid and Target

- Grid: replaced additive material blending with alpha compositing to prevent saturated reds washing to white on bright backgrounds; shifted radial-gradient colors toward stronger coral, reduced dot radius from 4.5 to 3.25 texture pixels.
- Reticle: stronger coral hue, lighter coral inner ring highlight and coral-tinted center, existing halo retained.
- Tag corner brackets: more saturated red; origin gizmo and tag axes unchanged.
- Wordmark: added a delicate bright-coral glow overlay to the Track text, preserved logo frame.
- Detector, recording, and Blender importer unchanged.

This build is not compiled or device-tested; validate with GitHub Actions and iPhone.
